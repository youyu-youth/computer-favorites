输入区设计 — 功能范围

对话输入框需要哪些能力？CS 学习场景下常见需求：文本、代码块、文件、快捷指令

A

纯文本输入

多行 textarea，支持 Shift+Enter 换行、Enter 发送。最简方案。

B

代码块快捷插入

输入框旁有"插入代码"按钮，弹出代码编辑器（语言选择 + 语法高亮），插入后以 Markdown 代码块发送。

C

文件/图片上传

支持拖拽/粘贴上传文件（代码文件 .java/.py 等）或截图，AI 可分析文件内容或图片。

D

快捷指令菜单

输入框左侧 "/" 按钮唤起指令面板：/explain（解释代码）、/optimize（优化）、/review（代码审查）、/translate（翻译）等。
