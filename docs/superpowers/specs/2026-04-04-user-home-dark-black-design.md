# 用户端首页暗黑纯黑化设计说明

## 1. 背景与目标

本设计用于满足以下需求：

- 仅在暗黑模式下生效。
- 仅针对用户端主页面（首页）进行纯黑背景改造。
- 导航栏、Footer、导航相关展开层（移动端菜单、头像下拉菜单）在暗黑模式下统一为纯黑背景。
- 文本与图标颜色保持现有主题逻辑，不进行全量重构。

## 2. 范围与非范围

### 2.1 范围内

- 用户端首页内容区背景。
- 用户端顶部导航主条。
- 用户端顶部导航的移动端展开菜单。
- 用户端头像下拉菜单。
- 用户端 Footer 背景。

### 2.2 范围外

- 亮色模式视觉。
- 非首页用户页面（如个人中心、设置等）视觉。
- 管理端主题与页面。
- 接口、状态管理、业务流程。

## 3. 设计原则

- 采用主题令牌驱动，不在业务组件中新增硬编码 HEX/RGB 常量。
- 通过首页作用域限定暗黑纯黑效果，避免污染其他路由。
- 变更只涉及展示层，不影响交互行为与数据流。

## 4. 方案选型

本次采用“方案 B 的范围化实现”：

1. 保持令牌体系作为样式来源。
2. 在首页路由容器增加作用域类，仅在首页生效。
3. 在暗黑 + 首页作用域条件下覆写关键背景变量为纯黑。
4. 导航与 Footer 的暗黑背景使用同一套变量来源，确保统一。

不采用“直接改用户端全局暗黑 token”的原因：

- 会扩散影响全部用户端页面，与“仅主页面”目标冲突。

## 5. 架构与组件改动设计

### 5.1 布局层作用域入口

文件：`computer-favorites-web/src/layouts/UserLayout.vue`

- 使用路由信息计算是否为首页。
- 首页时在外层容器增加作用域类，例如 `cf-home-black-dark-scope`。
- 该类只作为视觉作用域标记，不参与业务逻辑。

### 5.2 主题样式层变量覆写

文件：`computer-favorites-web/src/assets/styles/tailwind.css`

- 新增 `.dark .cf-home-black-dark-scope` 作用域样式。
- 在该作用域内覆写以下背景相关变量为纯黑：
  - `--cf-color-surface-page-rgb: 0 0 0`
  - `--cf-color-dark-bg-rgb: 0 0 0`
- 不调整文本变量，保持现有文本可读性策略。

### 5.3 导航栏纯黑一致性

文件：`computer-favorites-web/src/components/common/AppNavbar.vue`

- 导航主条暗黑背景读取纯黑变量效果。
- 移动端展开菜单暗黑背景统一纯黑。
- 头像下拉菜单暗黑背景统一纯黑。
- 保持现有 hover、focus、文字与图标逻辑不变。

### 5.4 Footer 纯黑一致性

文件：`computer-favorites-web/src/components/common/AppFooter.vue`

- Footer 暗黑背景统一纯黑。
- 暗黑边框继续使用既有边框语义变量，保留层次边界。

## 6. 数据流与状态影响

- 不新增 store，不改动 Pinia 状态结构。
- 不新增接口、不改动 API 请求。
- 不改动 i18n 文案。
- 仅新增一个基于路由的视觉作用域判断。

## 7. 错误处理与风险控制

### 7.1 路由命名变更风险

- 风险：若首页路由名变化，作用域可能失效。
- 策略：采用路由 name 为主、path 兜底的双判定方式。

### 7.2 主题切换瞬态风险

- 风险：切换暗黑模式时出现短暂背景不一致。
- 策略：仅覆写变量值，沿用现有过渡时序，不新增复杂动画链路。

### 7.3 菜单层级视觉割裂风险

- 风险：主条、移动菜单、下拉菜单黑度不一致。
- 策略：统一在首页暗黑作用域中读取同一背景变量。

## 8. 验收标准

### 8.1 必须通过

1. 暗黑模式 + 首页：主背景纯黑。
2. 暗黑模式 + 首页：导航主条、移动菜单、头像下拉、Footer 全部纯黑。
3. 暗黑模式 + 非首页：保持现有视觉，不被纯黑改造影响。
4. 亮色模式：首页及其他页面视觉无变化。

### 8.2 交互回归

1. 导航菜单展开/收起行为不变。
2. 头像菜单展开/收起行为不变。
3. 路由跳转、页面滚动、固定头部行为不变。

## 9. 实施顺序建议

1. 在布局层增加首页视觉作用域类。
2. 在主题样式层补充暗黑首页变量覆写。
3. 调整导航与 Footer 的暗黑背景读取方式。
4. 完成亮暗模式 + 首页/非首页四象限回归验证。

## 10. 预期产出

- 首页暗黑模式视觉达到“背景纯黑 + 组件层次保留”目标。
- 变更边界明确，避免对用户端其他页面产生副作用。
- 后续若需要扩展全站纯黑，可在本作用域方案基础上平滑演进。
